# ppaH Control v1.22

Приложение для Android, которое автоматически управляет подключением при запуске приложений из пользовательского списка.
Позволяет отключать подключение для определённых приложений и восстанавливать его при переходе к другим приложениям или на главный экран.
Создавалось с целью минимизировать возможность утчеки IP адресов собственный серверов.

## 🚀 Возможности

- **Автоматическое отключение** - при запуске приложения из выбранного списка.
- **Восстановление подключения** - при выходе из выбранного приложения, если включена соответствующая настройка.
- **Отслеживание активного приложения** - через службу специальных возможностей Android.
- **Контроль состояния подключения** - отображение текущего статуса.
- **Проверка маршрутов** - отображение внешних адресов Direct IP и Tunnel IP с измерением времени ответа.
- **Управление списком приложений** - поиск, выбор и отображение системных приложений.

## 📱 Требования

- Android 8.0 или новее (совместимость с более ранними версиями не заявлена).
- Установленное приложение Happ.
- Разрешение на использование специальных возможностей.
- Разрешение на отображение поверх других окон.
- На некоторых устройствах — разрешение на открытие окон в фоновом режиме.

> Приложение разрабатывается и тестируется преимущественно на устройствах Xiaomi. На устройствах других производителей поведение системы может отличаться.

## ⚙️ Настройка

1. Установите и настройте Happ (per-app-split-tunneling) и ppaH Control.
2. Запустите ppaH Control.
3. Предоставьте необходимые разрешения.
4. Включите параметр **«Включить отслеживание»**.
5. Откройте раздел **«Список приложений»**.
6. Выберите приложения, при запуске которых необходимо отключать подключение.
7. При необходимости включите **«Восстанавливать подключение»**.

После настройки приложение работает автоматически.

## 🔄 Принцип работы

**При запуске выбранного приложения**

ppaH Control определяет активное приложение и отправляет команду отключения через Happ.

**При переходе к другому приложению**

Если включено автоматическое восстановление, ppaH Control отправляет команду восстановления подключения.

## 🔐 Разрешения

Специальные возможности | Определение активного приложения и переходов между окнами
Отображение поверх других окон | Поддержка управления из фонового режима
Доступ к интернету | Проверка внешних IP-адресов и времени ответа
Состояние сети | Определение текущего подключения
Доступ к списку установленных приложений | Отображение и выбор приложений

На устройствах Xiaomi может дополнительно потребоваться разрешение **«Открытие новых окон в фоне»**.
